HOW IT WORKS:

Command:
  scheduler --program hello.exe --interval 5s --repeat 10

Execution:
  [t=0ms]     Start hello.exe
  [t=25ms]    Finish hello.exe (25ms execution time)
  [t=5000ms]  Start hello.exe (waited 4975ms)
  [t=5025ms]  Finish hello.exe
  [t=10000ms] Start hello.exe
  ...
  [t=50000ms] Final execution

Output:
  - When each execution starts
  - When each execution finishes
  - Duration of each execution
  - Exit code (success/failure)
  - Timing statistics (min/max/average)
  - Total elapsed time
